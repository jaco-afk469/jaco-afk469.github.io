# OmniConvert - 100% Private In-Browser Image Converter

> Fast, free, and private image converter and compressor supporting WebP, PNG, JPEG, and SVG. 100% client-side execution — your images never leave your computer.

Website: [https://jaco-afk469.github.io/omniconvert/](https://jaco-afk469.github.io/omniconvert/)

---

## Key Features

* **100% Private (Zero Server Upload):** Conversion is performed entirely inside your web browser using HTML5 Canvas and client-side memory. No photos are ever uploaded or transmitted to any server.
* **Instant Speed:** No upload waits, no queuing, and no rate limits.
* **Multilingual & Auto-Detect:** Supports English, German, Spanish, Portuguese, French, and Italian, automatically adapting to the user's browser language.
* **Compression & Quality Control:** Fine-tune image quality with instant file size difference and savings calculations.
* **Mobile & Desktop Friendly:** Fully responsive modern interface built with Tailwind CSS.

---

## Tech Stack

* **HTML5 Canvas API:** High-fidelity client-side image rendering and compression.
* **Tailwind CSS:** Modern responsive layout.
* **Client-Side i18n:** Zero-dependency multilingual dictionary with automatic locale fallback.
